🗄️ Database Design

Core Tables: users # Authentication & roles ├─ id, username, password, role areas # Campus zones/buildings ├─ id, name, map_code, description rooms # Physical locations ├─ id, description, x, y, floor, map_code sensors # Monitoring devices ├─ id, room_id, x, y, status, map_code zones # Map configurations ├─ map_code, path, timestamps

Key Relationships

• Users authenticate with role-based access
• Areas contain multiple rooms
• Rooms can have sensors
• Zones define map layouts

🚀 Quick Setup Guide

# 1. Clone repository git clone https://github.com/ShalevOzeri/Active_rooms.git cd Active_rooms # 2. Install dependencies cd server && npm install cd ../client && npm install # 3. Setup database mysql -u root -p < server/active_rooms.sql # 4. Configure environment cp server/.env.example server/.env # Edit .env with your database credentials # 5. Start application cd server && npm start cd ../client && npm start
